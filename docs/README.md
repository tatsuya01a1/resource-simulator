## 確定事項と初期案

要件定義書第2章がユーザー指定の制約をまとめている。要件定義書第7章と基本設計書第14章は初期案・未決事項の参照先である。初期案を確定要件へ読み替えない。

数値モデルは基本設計書第4章に一元化する。API契約は第9章、対応する検証の期待結果は要件定義書第8章で確認する。公式資料へのリンクは基本設計書第15章にあり、実装・公開直前に再確認する。
